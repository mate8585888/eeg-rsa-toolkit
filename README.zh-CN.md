# EEG-RSA 一键分析工具

[English](README.md)

面向任务态 EEG 的 Python 图形化 RSA 工具：读取 EEGLAB .set，选择条件和时间窗，计算 Neural RDM，并与 Model RDM 比较。

## 开始使用

安装 Python（启动器建议 3.10 或 3.11）后，双击 `启动_RSA.bat`，首次运行会安装依赖。优先使用已预处理、已分段的 `.set`；外部 `.fdt` 须与 `.set` 放在一起。详见 [完整使用说明](README_使用说明.md)。

## 适用范围

基础版分析指定时间窗内的条件空间模式。相关 p 值不能替代组水平统计、置换检验或多重比较校正。原有分发包保存在 `downloads/`。

本次上传保留原有工具文件，检查文件一致性及适用的 Python 语法；不将上传检查等同于科学有效性验证或完整应用测试。
